# Security and privacy reports

Please do not post sensitive activity histories or security details in a public issue. Send a private report to **furkiak@gmail.com** with a short reproduction and the affected revision. Avoid attaching real `stats.json` unless strictly necessary; a redacted sample is preferable.

The project currently has no cloud synchronization or account system. Activity history and exports should be treated as private local data. See [data handling](docs/DATA.md).
